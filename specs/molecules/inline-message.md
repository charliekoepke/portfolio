# Inline message

An inline message explains a condition for one section of the page. It stays until the condition changes. It can offer a next step.

Default structure follows [section message](https://atlassian.design/components/section-message/usage) and [inline message](https://atlassian.design/components/inline-message) in the [Atlassian Design System](https://atlassian.design/design-system).

## Default example

Title: "This case study is still a draft." Description: "Publish it when the outcome section is ready." Action: "Edit the draft".

## Appearance

Padding is 16px. Radius is 4px. The title is 16px Inter 600. The description is 16px, 8px below the title. Info uses `#E7EEF6` and `#1D4E89`. Warning and error use their status pairs. The icon is a navy stroke. The action is a link, not a primary button.

## Rules

- Put the message in the section it concerns.
- The title names the situation. The description says what to do next.
- Do not rely on color alone. The text says whether it is a warning or an error.
- A site-wide failure uses a banner. A brief confirmation uses a flag.
