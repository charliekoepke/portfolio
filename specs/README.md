# Portfolio design system

Specs for the portfolio site. Read these before generating UI so tokens and components stay consistent.

- `foundations/` — color, type, spacing, motion, and other base rules
- `tokens/` — named tokens that implement the foundations
- `atoms/` — smallest components
- `molecules/` — components composed of atoms
- `organisms/` — page-level sections
- `patterns/` — layout and interaction patterns
- `tokens.css` — token values consumed by the site
- `scripts/token-audit.js` — checks tokens against the specs
