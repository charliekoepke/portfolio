# Token reference

## Color

Defined in `color-tokens.md` and `tokens.css`.

## Typography

Defined in `typography-tokens.md` and `tokens.css`.

## Radius

`--radius-button` is 50px. `--radius-checkbox` and `--radius-field` are 4px. All three are in `tokens.css`.

## Spacing

Defined in `spacing-tokens.md` and `tokens.css`. The base unit is 8px.

## Icon

`--icon-size` is 1.5rem (24px). `--icon-stroke` is 2px. Both are in `tokens.css`. Icon color uses the navy action, inverse, and disabled text tokens.

## Elevation

Defined in `elevation-tokens.md` and `tokens.css`.

## Motion

Defined in `motion-tokens.md` and `tokens.css`.

## Layers

Defined in `layer-tokens.md` and `tokens.css`. `--opacity-blanket` is 0.4.
