# Content panel

A content panel is a container for a block of related content beside or inside the page. It has a title and a body.

Default structure follows [panel](https://atlassian.design/components/panel) in the [Atlassian Design System](https://atlassian.design/design-system).

## Default example

Title: "Role". Body: "Product design for clinical tools." An optional link "Read the bio" sits at the end of the body.

## Appearance

White surface, 1px `#D0D9E6` border, 4px radius, 24px padding. The title is 20px Montserrat 600. The body is 16px, 8px below the title. Sections inside the panel are 16px apart.

## Rules

- The title is a heading one level below the page title.
- A panel supports the page. It does not contain a second page header.
- Actions inside a panel are a link or a secondary button. The page's primary button stays in the page header.
