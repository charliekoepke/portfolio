# Radius

Buttons, badges, and icon buttons use a pill radius of 50px (`--radius-button`). On a 40px text button and a 24px badge, that radius resolves to a full pill. On a 40px icon button, it resolves to a circle.

The checkbox uses a 4px corner (`--radius-checkbox`). On a 16px box, that keeps a short corner without turning the control into a circle.

The text input uses the same 4px corner (`--radius-field`).
