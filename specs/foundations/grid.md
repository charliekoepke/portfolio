# Grid

Page structure uses the 8px spacing scale in `foundations/spacing.md`.

The page is 12 columns at 64rem and wider, 8 columns from 48rem, and 4 columns below that. Gutters are 24px. Page margins are 32px, 24px, and 16px at those same widths. See `foundations/breakpoints.md`.

Component padding and the gaps inside a component use the same 8px scale.
